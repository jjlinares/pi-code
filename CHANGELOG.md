# Changelog

All notable changes to Pi Code are documented in this file.

## 0.1.0

- Run Pi's native TUI in VS Code's integrated Terminal view.
- Open an existing Pi terminal or create independent sessions.
- Add editor selections and Explorer files to Pi's composer as workspace-relative references.
- Add selected terminal output to Pi's composer as quoted context.
- Resolve Pi from VS Code's inherited `PATH` or the machine-scoped `pi-code.path` setting.
- Include the standalone Pi Clipboard Bridge for image paste in devcontainer terminals.
